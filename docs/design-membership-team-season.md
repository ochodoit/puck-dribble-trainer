# 설계: 정회원·추천코드 · 팀(길드) · 월간 시즌 · 명예의 전당

확정 사항: 아래 4가지는 모두 추천안으로 결정 (2026-11-16)
- 시즌 점수 = 실력 포인트 + 연습 포인트
- 팀 순위 = 팀원 상위 5명 평균
- 팀 인원 = 최대 30명
- 명예의 전당 = 운영자 확정 후 공개

## 1. 회원 등급 (절충안: 게스트는 자유롭게, 정회원은 추천코드로)

| | 게스트 | 정회원 (추천코드로 가입) |
|---|---|---|
| 게임·자유 연습 | O | O |
| 커뮤니티 읽기, 코스 연습 | O | O |
| 랭킹·월간 시즌 점수 | X (결과 화면에 "정회원이었다면 ○위" 표시) | O |
| 글쓰기·기록 게시판·응원 | X | O |
| 팀 가입·만들기 | X | O |
| 추천코드 | – | 3장 + 활동 보상으로 추가 |

- 정회원 번호 배지(#0007)와 "누구의 추천"이 프로필에 남음
- 추천코드 추가 지급 예: 10게임 완주, 기록 게시판 1위 → +1장
- 추천 링크: 코드가 들어 있는 링크를 공유하면 카톡 등에서 미리보기 카드 표시
- 첫 코드는 운영자 화면에서 발급해 직접 배포

## 2. 팀(길드)
- 정회원이 팀 이름 + 로고로 생성, 만든 사람 = 주장
- 주장이 팀 초대 링크/코드 발급. 게스트가 이 코드로 들어오면 정회원 가입 + 팀 가입이 한 번에 (코치용 팀 코드)
- 팀당 최대 30명, 한 사람은 한 팀만
- 팀 이동은 월 1회, 그 달에 쌓은 점수는 원래 팀에 남음
- 팀 화면: 로고, 멤버, 이번 달 팀 순위, 팀 내 순위
- 로고: 올릴 때 작은 정사각형 이미지로 자동 축소해 데이터베이스에 저장. "직접 만든 로고만" 안내 (실제 구단 로고 저작권)

## 3. 월간 시즌 점수
- 실력 포인트: 모드별 그 달 최고 기록의 순위를 포인트로 환산 (1위 100점, 순위가 낮을수록 감소), 모드별 합산
- 연습 포인트: 끝까지 마친 게임 1판당 1점, 하루 최대 10점
- 개인 순위 = 실력 + 연습 포인트 (연령대별 순위도 표시)
- 팀 순위 = 팀원 상위 5명 평균
- 매달 1일 0시(한국 시간) 새 시즌 시작, 지난달 기록은 수정 불가로 잠금

## 4. 명예의 전당
- 매달 팀 1~3위(로고와 함께), 개인 1~3위, 연령대별 1위
- 지난 달들을 영구히 쌓아서 표시
- 수상 배지(예: "2026.12 팀 우승")를 프로필과 자랑용 결과 카드에 표시
- 달이 끝나면 운영자가 확정 버튼으로 공개 (확정 전 이상한 기록 삭제 가능)

## 5. Firebase 무료 요금제 안에서의 구현
- 로고: Storage는 새 프로젝트에서 유료 전환이 필요하므로, 축소한 이미지를 Firestore 문서에 직접 저장
- 월말 집계: Functions도 유료라 사용하지 않음. 순위는 화면에서 계산, 명예의 전당은 운영자 확정
- 보안 규칙으로 막는 것: 추천코드 없이 정회원 되기, 남의 팀 무단 가입, 지난달 기록 수정
- 운영자 화면: 추천코드 발급, 팀·로고 숨기기, 기록 삭제, 명예의 전당 확정
- 가입 화면에 "실명 대신 별명" 안내 (아이들 사용자, 명예의 전당 공개)

## 6. 진행 순서
1. Firebase 연결과 실제 동작 확인
2. 정회원·추천코드·운영자 화면 → 배포
3. 팀(길드)·팀 초대 코드·로고
4. 월간 시즌 포인트·명예의 전당
5. 자랑용 결과 카드 이미지·추천 링크 미리보기
