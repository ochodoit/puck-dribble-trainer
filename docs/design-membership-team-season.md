# 설계: 정회원·추천코드 · 팀(길드) · 월간 시즌 · 명예의 전당

## 2026-11-17 조정 (1단계 구현됨)
- **베타 기간**: 운영자가 배포한 **베타 링크**로 가입하면 바로 정회원(베타 멤버 배지). 링크 하나를 여러 명이 쓰고, 마감일이 지나면 서버 시간 기준으로 자동 마감. 인원 상한 선택. 코드 도입 전 가입자도 베타 멤버로 전환(가입 순서대로 번호)
- **코드 없이 오면**: 게스트로 플레이 → 결과 화면에 "정회원이었다면 ○위" + "플레이 영상을 인스타에 올리고 공식 계정으로 DM을 보내 주면 정회원 가입 코드를 DM으로 보내 드림" + **인스타 DM 보내기** 버튼. 운영자가 확인 후 **1회용 코드**(코드만, 또는 링크)를 DM으로 보냄 (메일 안내는 없앰 — DM이 더 간편, 메일 주소를 받지 않아도 됨)
  - 안내 문구: 보호자와 함께, 얼굴 없이 판과 퍽만 나와도 됨, 비공개 계정이면 영상이나 캡처를 DM에 함께
  - 공식 인스타 계정·해시태그는 운영자 화면에서 입력
- **베타 멤버의 정회원 유지**: 베타 종료일(운영자가 정함) 전에 커뮤니티 **[개발자에게]**로 좋았던 점·고쳤으면 하는 점을 보낸 베타 멤버만 정회원 유지. 못 보낸 멤버는 종료일 뒤 랭킹 등록·글쓰기·응원이 막히고(플레이는 됨) 인스타 DM으로 문의 → 운영자가 손으로 '정회원 유지' 가능. 처음 보낸 시각은 서버 시간으로 남아 규칙이 종료일과 비교
- **접속 코드(PIN) 화면 제거**: 게스트는 누구나, 정회원은 가입 코드로
- **운영자**: Firestore `admins/{uid}` 문서로 판별 (앱 코드의 별명 목록 대신)
- **코치용 팀 코드**: 나중 업데이트로 미룸
- **2단계 (베타 끝나기 전)**: 친구 추천 링크로 가입. 새로 가입하면 내 추천코드 3장, 1장 = 친구 1명, 안 쓴 코드 보유 최대 3장, **출석 7일(누적, 게임을 끝까지 한 날, 서버 날짜 기준 하루 1번)마다 1장 추가**, 3장이 꽉 찼으면 그 보상은 넘어감. 베타가 끝나는 순간 모든 정회원에게 3장 지급
  - 아래 1절의 "활동 보상(10게임 완주, 기록 게시판 1위)"은 출석 7일 보상으로 바뀜

확정 사항: 아래 4가지는 모두 추천안으로 결정 (2026-11-16)
- 시즌 점수 = 실력 포인트 + 연습 포인트
- 팀 순위 = 팀원 상위 5명 평균
- 팀 인원 = 최대 30명
- 명예의 전당 = 운영자 확정 후 공개

## 1. 회원 등급 (절충안: 게스트는 자유롭게, 정회원은 추천코드로)

| | 게스트 | 정회원 (추천코드로 가입) |
|---|---|---|
| 게임·자유 연습 | O | O |
| 커뮤니티 읽기, 코스 연습 | O | O |
| 랭킹·월간 시즌 점수 | X (결과 화면에 "정회원이었다면 ○위" 표시) | O |
| 글쓰기·기록 게시판·응원 | X | O |
| 팀 가입·만들기 | X | O |
| 추천코드 | – | 3장 + 활동 보상으로 추가 |

- 정회원 번호 배지(#0007)와 "누구의 추천"이 프로필에 남음
- 추천코드 추가 지급 예: 10게임 완주, 기록 게시판 1위 → +1장
- 추천 링크: 코드가 들어 있는 링크를 공유하면 카톡 등에서 미리보기 카드 표시
- 첫 코드는 운영자 화면에서 발급해 직접 배포

## 2. 팀(길드)
- 정회원이 팀 이름 + 로고로 생성, 만든 사람 = 주장
- 주장이 팀 초대 링크/코드 발급. 게스트가 이 코드로 들어오면 정회원 가입 + 팀 가입이 한 번에 (코치용 팀 코드)
- 팀당 최대 30명, 한 사람은 한 팀만
- 팀 이동은 월 1회, 그 달에 쌓은 점수는 원래 팀에 남음
- 팀 화면: 로고, 멤버, 이번 달 팀 순위, 팀 내 순위
- 로고: 올릴 때 작은 정사각형 이미지로 자동 축소해 데이터베이스에 저장. "직접 만든 로고만" 안내 (실제 구단 로고 저작권)

## 3. 월간 시즌 점수
- 실력 포인트: 모드별 그 달 최고 기록의 순위를 포인트로 환산 (1위 100점, 순위가 낮을수록 감소), 모드별 합산
- 연습 포인트: 끝까지 마친 게임 1판당 1점, 하루 최대 10점
- 개인 순위 = 실력 + 연습 포인트 (연령대별 순위도 표시)
- 팀 순위 = 팀원 상위 5명 평균
- 매달 1일 0시(한국 시간) 새 시즌 시작, 지난달 기록은 수정 불가로 잠금

## 4. 명예의 전당
- 매달 팀 1~3위(로고와 함께), 개인 1~3위, 연령대별 1위
- 지난 달들을 영구히 쌓아서 표시
- 수상 배지(예: "2026.12 팀 우승")를 프로필과 자랑용 결과 카드에 표시
- 달이 끝나면 운영자가 확정 버튼으로 공개 (확정 전 이상한 기록 삭제 가능)

## 5. Firebase 무료 요금제 안에서의 구현
- 로고: Storage는 새 프로젝트에서 유료 전환이 필요하므로, 축소한 이미지를 Firestore 문서에 직접 저장
- 월말 집계: Functions도 유료라 사용하지 않음. 순위는 화면에서 계산, 명예의 전당은 운영자 확정
- 보안 규칙으로 막는 것: 추천코드 없이 정회원 되기, 남의 팀 무단 가입, 지난달 기록 수정
- 운영자 화면: 추천코드 발급, 팀·로고 숨기기, 기록 삭제, 명예의 전당 확정
- 가입 화면에 "실명 대신 별명" 안내 (아이들 사용자, 명예의 전당 공개)

## 6. 진행 순서
1. Firebase 연결과 실제 동작 확인
2. 정회원·추천코드·운영자 화면 → 배포
3. 팀(길드)·팀 초대 코드·로고
4. 월간 시즌 포인트·명예의 전당
5. 자랑용 결과 카드 이미지·추천 링크 미리보기
