퍽을 읽는 스틱 핸들링 게임. 당신의 실력을 보여주세요


        

        
로그인하지 않으면 게스트로 시작합니다 (랭킹 미등록)

        
        

          
          
        

        
        

          

            
            
            
            
          

          

            

              
              
            

            

              
이제 로그인은 아이디로 합니다. 아이디와 새 비밀번호를 만들어 주세요. 별명과 기록은 그대로예요. 예전 계정: 

              
임시 비밀번호로 로그인했어요. 나만 아는 새 비밀번호를 정해야 시작할 수 있어요. 아이디: 

              
              
              
              
              
              
              
              
              
              
스틱
                

                  
                  
                

              

            

            
아이디는 로그인에만 쓰고 공개되지 않아요 (4~20자, 영문 소문자로 시작, 영문·숫자·_). 별명은 랭킹에 공개되니 실명 대신 쓰고, 아이디와 다르게 정하세요. 비밀번호는 8자 이상, 영문과 숫자를 함께 넣으세요.

            
정회원은 가입 코드로 가입합니다. 코드가 없으면 게스트로 플레이하고, 결과 화면의 안내대로 플레이 인증을 하면 코드를 받을 수 있어요.

            
예전에 별명과 숫자 6자리로 가입했다면 별명과 그 비밀번호로 로그인하세요. 아이디를 한 번 새로 만들게 됩니다.

            

              
              

                
가입할 때 메일 주소를 받지 않아서 비밀번호 찾기 메일은 보낼 수 없어요. 공식 인스타그램으로 DM을 보내 주세요.

                
    
                  
  1. DM에 아이디(모르면 별명), 팀 이름, 나이, 스틱(L/R), 가입한 때(대략)를 적어 주세요.
    2. 
                  
  2. 운영자가 확인한 뒤 임시 비밀번호를 DM으로 보내 드려요.
    3. 
                  
  3. 임시 비밀번호로 로그인하면 바로 새 비밀번호를 정하게 됩니다.
    4. 
                

                

                
어린이 회원은 보호자가 대신 보내 주세요. 운영자는 DM으로 비밀번호를 먼저 묻지 않아요.

              

            

            

            

              
              
              
            

          

          

        

        

          처음이라면 — 사용 방법
          
    
            
  1. 세우기 — 휴대폰·아이패드·노트북을 거치대에 세워 전면 카메라로 자신과 바닥이 보이게 둡니다.
    2. 
            
  2. 영역 — 네 모서리를 끌어 바닥에 맞춥니다. 다음부터는 맞춰 둔 영역을 그대로 씁니다.
    3. 
            
  3. 퍽 등록 — 공·뚜껑·퍽 무엇이든 가운데 원 안에 3초 두면 인식됩니다. 배경과 색만 다르면 됩니다.
    4. 
            
  4. 움직여 보기 — 퍽을 네 모서리 표적에 가져가 끝까지 잘 잡히는지 확인한 뒤 게임을 고릅니다.
    5. 
            
  5. 시작 — 등록된 퍽을 원 안에 3초 두면 손대지 않고 시작합니다. 휴대폰을 TV에 연결해도 됩니다.
    6. 
          

        

        
퍽 드리블 트레이너는 휴대폰·아이패드·노트북 카메라로 퍽과 스틱을 인식해, 집에서 아이스하키 스틱핸들링을 훈련하는 무료 웹 게임입니다. 앱 설치 없이 브라우저에서 바로 시작합니다.

회원 현황

통계

          
회원 기준(가입·출석·플레이)입니다. 방문자 수와 게스트 플레이는 Google 애널리틱스에서 봅니다.

운영자 비밀번호

          
운영자 계정은 12자 이상 비밀번호를 쓰세요 (일반 회원은 8자 이상).

          

            
            
            
            
          

          

        

        

          
1회용 코드

          
SNS 플레이 인증(올린 영상 링크)을 DM으로 확인한 게스트에게 코드(또는 링크)를 보냅니다. 한 사람만 쓸 수 있습니다.

          

            
            
          

          

        

        

          
오픈베타 링크

          
여러 명이 같은 링크로 가입합니다(예: 12월 31일까지 100명). 마감일이 지나거나 인원이 차면 자동으로 막힙니다.

          

            
            
            
            
          

          

        

        

          
게스트 안내

          
게스트의 결과 화면에 나오는 정회원 코드 받는 방법입니다. 정회원 친구의 초대 링크로 가입하거나, 플레이 영상을 SNS에 올리고 그 링크를 공식 인스타 DM으로 보내도록 안내합니다.

          

            
            
            
          

        

        

          
베타 기간

          
무료 정회원은 가입 경로(오픈베타 링크·친구 초대·1회용 코드)와 상관없이 종료일까지입니다. 종료일 다음부터는 랭킹 등록·글쓰기가 막히고, '정회원 유지'(기한 없음)와 '3개월 이용권' 회원만 정회원으로 남습니다. 친구 초대 코드도 종료일에 마감됩니다.
